# Sources natives PASS21 — conservation sans perte

Ces ZIP contiennent les versions exactes lues au gel du lot 1 : illustrations, essais rejetés, références, métadonnées et preuves avec leurs statuts littéraux. Ils ne certifient pas l'achèvement ou la fidélité de ces créations.

Les objets identiques sont stockés une fois. Le document `../metadata/SOURCE_SNAPSHOT_ACTUAL_V1.json` conserve chaque nom original, son empreinte et ses qualifications. `LOSSLESS_SOURCE_INDEX_ACTUAL_V1.json` épingle chaque ZIP. Toutes les entrées ont été décompressées et comparées aux octets originaux ; tous les CRC ont été vérifiés.

Restauration des fichiers réguliers : `python3 restore_native_sources.py --restore-to DOSSIER_VIDE`.

Les 3 332 chemins de conservation déjà publiés restent inchangés. Les sources locales, les ZIP fournis par l'utilisateur et les candidats de travail ne sont pas supprimés. Les versions créées après ce gel feront l'objet d'un lot suivant.
