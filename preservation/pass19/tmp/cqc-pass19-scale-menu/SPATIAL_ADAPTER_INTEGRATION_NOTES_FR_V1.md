# Adaptateur spatial Versus — livraison isolée Pass19

Le plan `VERSUS_SPATIAL_GUARDED_PATCH_PLAN_V1.json` comporte 50 remplacements exacts dans le moteur actif Pass8, les grenades Chaff Pass7 et le HTML actuel, plus le nouveau module `cqc-pass19-versus-spatial.js`. Il garde chaque texte attendu, le nombre de correspondances et les SHA avant/après. Aucun fichier de l'application Root ou du Pass18 original n'a été écrit par cet agent.

Le module convertit les rectangles de contact autour des pieds avec `simulationRatio(fighter)`. Les images continuent d'utiliser leur ratio de source/costume via `CQC_PASS19_WORLD_SCALE`. Les dégâts, statistiques, coûts, vitesses, gravités et durées des techniques restent ceux de leurs profils. Les choix de distance du CPU suivent la même géométrie. Les petites créatures peuvent préciser `combat.simulationBody={width,height,crouchHeight}` en coordonnées de leur corps logique de référence ; les hurtboxes Sunny déjà revues restent prioritaires.

Les projectiles, télégraphes et éclairs de bouche utilisent une origine commune. `CQC_PASS19_NATIVE_ORIGINS.projectile(p,m)` reçoit la priorité et fournit des coordonnées locales mesurées à `entry.displayHeight`, sans facteur 1,12 ni ratio déjà appliqué. L'adaptateur multiplie une fois par le ratio **de source** et le facteur historique de dessin 1,12. Le Gekko possède également deux bouches réellement vues dans ses pièces natives, protégées par SHA, rectangle et pivot ; leur transformation utilise la matrice de sa pièce « gun ».

Le rendu normal, les projectiles, les FX, les repères de contact, les couches de stage et la chorégraphie des finishers partagent leur caméra. Le HUD et les titres de finisher restent en coordonnées d'écran. Le drapeau `CQC_PASS19_SPATIAL_SCALE_READY` devient vrai seulement après l'enregistrement des contrats du moteur et du rendu. Ce module n'est chargé que dans Versus.

Les hurtboxes historiques conservent leurs marges de jeu. Pour le Gekko, elles englobent principalement les jambes ; le canon et le hull ne deviennent pas une nouvelle cible par cette conversion. Elles sont cohérentes dans l'espace commun, mais ne constituent pas un tracé anatomique certifié. Les boss Core et leurs points faibles gardent leur cadrage historique ; aucune échelle canonique de combat Core n'est annoncée. Les tailles non attestées et les créations originales conservent leur qualification dans le registre des hauteurs.

Preuves de base : `VERSUS_SPATIAL_ACTUAL_MATH_QA_V1.json` (17 contrôles, dont 600 frames identiques à ratio 1), `VERSUS_SPATIAL_ACTUAL_BROWSER_QA_V1.json` (rendu réel Gekko/Solid, Sunny, Raven et tir Gekko), `GEKKO_MACHINE_GUN_ANCHOR_SOURCE_PIXELS_ACTUAL_V1.json` (sources visuellement examinées et alpha des bouches). Les reçus complémentaires portent leur propre numéro de version et sont conservés séparément.
