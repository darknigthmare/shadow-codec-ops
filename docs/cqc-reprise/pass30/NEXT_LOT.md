# Travaux suivants conservés — Pass30

Les nouvelles sources de Gander, le Power Unit conventionnel de ZEKE, les pinces/câbles natifs des Mk, les anneaux du BIC et le pilote MGR sont raccordés. La suite conserve la distinction entre une pièce manquante et une affirmation de canon non attestée.

| Chantier | Travail concret restant |
| --- | --- |
| REX MGS4 | Produire le rig et ses pièces propres ; conserver l'identité distincte du REX MGS1. |
| Arsenal Gear | Compléter les sections extérieures absentes de la source. |
| Peace Walker | Produire la forme bipède et sa transition depuis la forme quadrupède. |
| Gander | Produire les surfaces cachées et les autres caméras à partir de références ; améliorer les petites frontières de découpe au mouvement. Les proportions et la caméra principale sont reprises dans Pass30. |
| ZEKE | Produire des sources attestées de capots ouverts/missiles en sortie. Raccorder les effets de lancement Core tout en conservant ses trajectoires et horloges. Garder le lanceur nucléaire de concept comme configuration distincte. |
| Mk.II/Mk.III | Produire le câble et la coque de service pour les caméras où ces sources sont absentes ; ajouter une déformation fidèle continue du câble. Toute commande de service jouable doit avoir un usage de gameplay défini. |
| BIC | Rechercher des vues supplémentaires du lancement. Les trois cibles logiques CQC ne prouvent pas l'existence de trois pinces articulées dans Portable Ops. |
| Membres et chenilles | Produire les doigts de pieds encore indivisibles, les phases axiales des vis de Shagohod et les bandes de chenille indépendantes. |
| Grands duels | Vérifier les autres coques mécaniques avant d'étendre les volumes source. Les corrections physiques ciblées de Pass30 concernent Hammerhead et Khamsin ; les autres profils conservent leurs volumes historiques. |
| Pilote Revengeance | Produire les sprites propres au corps blanc du prologue R-00, sans remplacer le corps noir ou fusionner Raiden MGS4 avec MGR. |
| Mesures | Conserver comme inconnues les dimensions canoniques non documentées ; reprendre les cadrages historiques encore qualifiés. |
| Costumes privés en attente | Conserver les quatre lots Gala/Cyborg/NextGen et leurs poses non admis des lots précédents jusqu'à validation visuelle. |

Les autres demandes historiques restent conservées : combattants manquants, variantes rétro et next gen réellement redessinées, costumes propres à la même époque, cyborgs cohérents avec Revengeance, scènes multicouches, menus et codec fidèles, campagnes, effets et liaisons entre modes. Ce lot ne déclare pas toute la franchise ni tous ces chantiers achevés.

Le prochain lot doit valider chaque pièce au repos, dans la marche, l'attaque et la rupture lorsque ces états existent pour la pièce et la rencontre, puis dans un vrai mode de jeu. Une source disponible mais non déclenchée par les champs d'animation réels doit être raccordée avant de déclarer son comportement jouable.
