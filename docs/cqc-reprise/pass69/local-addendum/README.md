# P69 — complément des fichiers locaux antérieurs

Six journaux et instantanés locaux de P67/P68 sont conservés ici, octet pour octet, après comparaison avec les blobs déjà publiés. Ils se trouvaient à côté du dossier de travail et n’étaient pas présents sous cette forme dans la PR.

Le [manifeste](manifest.json) donne leur origine, leur taille et leurs empreintes. Ce sont des traces historiques : elles ne remplacent ni les résultats de P69 ni les registres publiés. Le plan P68 de ce dossier est une version intermédiaire, antérieure au [plan canonique publié](../../pass68/publication-plan.json).

Les dumps d’arbres Git et les copies de comparaison sont reconstructibles depuis les commits ; les caches HTML servent à la recherche. Les références d’images réellement utilisées sont conservées séparément avec les nouveaux assets.
