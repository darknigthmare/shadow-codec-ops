# Complément de reprise P41 — six sources indispensables

Ce delta conserve seulement l’outil de correction des neuf points natifs, ses quatre jobs d’entrée et la carte mesurée des onze morceaux du Blackfoot. Les quatre jobs finaux, leurs géométries et leurs livres de poses sont déjà dans le complément v5. Les contrôleurs Blackfoot restent dans v6. Ces six textes ne changent aucun jeu.

Les préfixes de chemins sont remplacés par les quatre jetons documentés dans le manifeste. Leur inversion reproduit exactement les octets et SHA des six originaux. Le script hydrate-editing-export.py reste la copie inchangée SHA256 4eb47f6f34ffb74c72f43719b085b95c0582a385fdec20321ed33a90107ac8e3 ; il est conservé sans avoir été exécuté ici. Il vérifie les manifestes, exige une destination neuve et n’exécute aucun outil archivé. Les dépendances et leurs anciens SHA devront être revus après tout changement de racine.

Neuf PNG requis sont seulement liés par SHA et objets raw immuables dans EDITING_NATIVE_SOURCE_BINDINGS.json : huit sources de camouflage inchangées et le PNG droit du Blackfoot. Aucun PNG, JPEG, image encodée ni référence photographique n’est inclus dans ce delta. Les reçus de lecture cités attestent une sauvegarde antérieure ; cette préparation ne refait aucun accès réseau.

Le Blackfoot reste un travail partiel orienté à droite, admitted:false, sans admission au jeu. Le TT77 reste en attente ; Hideo reste limité aux portraits et aucun corps jouable n’est ajouté. Les textes, scripts et anciens avis sont des données historiques à relire : ils ne constituent aucune autorisation d’exécution, de génération, de modification du catalogue ou de publication. Le fichier de plan local et le handoff local restent hors de l’archive publique.
