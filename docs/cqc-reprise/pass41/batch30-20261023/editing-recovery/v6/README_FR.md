# P41 — complément éditable borné

Ce complément contient 54 textes : les recettes finales de calibration Gala et leurs entrées exactes, les derniers outils et preuves du HUD, ainsi que les contrôleurs et preuves JavaScript Blackfoot/Hideo absents des archives précédentes. 1 fichiers identiques par chemin relatif et empreinte d’origine sont exclus de la duplication ; leur archive est épinglée dans les contrôles. Le grand inventaire de 333 fichiers ne fait pas partie de ce complément.

Les quatre marqueurs de racine sont inversibles. Chaque texte décodé a retrouvé exactement son empreinte après inversion et après une simulation de racines choisies. Les gzip, s’il y en a, peuvent changer d’enveloppe compressée. Aucun outil archivé, contrôleur, test ni hydrateur n’a été exécuté pendant cette préparation.

L’hydrateur inchangé contrôle les empreintes avant toute écriture dans un dossier neuf : `python hydrate-editing-export.py . dossier-neuf --manifest-sha256 EMPREINTE`. Les options `--app-root`, `--workspace-root` et `--scratch-root` choisissent les autres racines. Il matérialise les textes sans exécuter leur code. Les images natives sont conservées dans une archive séparée ; aucune image brute ou encodée n’est intégrée ici. Les fichiers antérieurs restent nécessaires pour certaines dépendances. Après matérialisation, inspecter les dépendances absentes ou modifiées et réépingler explicitement les entrées avant toute exécution.

Les neuf jobs du manifeste final restent les seuls liens Gala actuels. Les entrées historiques des six recettes servent à reproduire leurs transferts de calibration ; elles ne deviennent pas de nouveaux jobs actifs. Blackfoot reste en attente de combat ; Hideo désigne uniquement son dossier de portraits. La preuve HUD courante est V3, qui confirme déplacement et saut non nuls. La qualification de l’ancien essai V2 est conservée pour écarter son ancien libellé de mouvement trop large. Aucune admission ou approbation n’est héritée d’une copie normalisée.
