# P41 — sources éditables, paquet 01

Ce paquet préserve 28 prompts soumis et le script candidat du dossier Hideo. Les textes et le code sont conservés octet pour octet. Les noms des versions distinguent les essais et les corrections ; leur présence ne vaut pas admission au jeu.

Les prompts couvrent les 25 planches de camouflages déjà générées, y compris DODODO v1/v2 en attente pour leur motif et Banana LEFT v2, ainsi que les trois portraits Hideo. Le code Hideo affiche uniquement ces dossiers et ne crée aucun corps jouable.

Les outils, rôles et calibrations des autres chantiers feront un paquet séparé une fois leurs versions finales figées. Aucun reçu de génération, identifiant privé, profil navigateur ou correspondance d’origine privée n’est publié.
