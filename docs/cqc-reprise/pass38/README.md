# P38 — Portée des projectiles Archive

Dans les formations élargies, certains tirs correctement dirigés disparaissaient avant de rejoindre leur cible. Le moteur retient désormais la durée minimale nécessaire pour atteindre la boîte de collision capturée au départ du tir, lorsque le rayon de l’arme la croise réellement.

Le calcul utilise la bouche et la vitesse réelles. Il tient compte de l’ordre de décrémentation propre aux tirs ennemis et au pistolet joueur, ainsi que des marges de collision existantes. La cible capturée ne guide pas le projectile après son départ. Les contacts mobiles, les tirs hors axe et les durées déjà suffisantes sont conservés.

Le même JavaScript est partagé octet pour octet par le paquet autonome et le runtime intégré. Le manifeste est régénéré depuis le paquet source et la parité des 2 674 fichiers accessibles est vérifiée. Aucune illustration, incarnation, articulation ou échelle n’est changée dans ce lot.

Les vérifications du moteur couvrent les sept profils natifs, les émissions réelles, les trajectoires, les collisions, les cas limites, la pause et les budgets de salves. Le détail des contrôles et leurs limites figure dans NATIVE_COMPLETION.json ; la livraison conserve les preuves et l’état GitHub/Vercel effectivement observés.

La pression de certaines salves augmente parce que leurs tirs arrivent désormais à destination. Des sessions de difficulté sur toutes les phases restent à poursuivre. Le backlog historique intégral est conservé dans NEXT_LOT.md.
