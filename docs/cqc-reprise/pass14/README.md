# CQC — Metal Gear D, TX-55 et hangar de REX

Ce lot ajoute les assemblages natifs par parties de Metal Gear D (Metal Gear 2, MSX2) et du TX-55 (Metal Gear, MSX, 1987) dans CQC autonome et le module CQC de Shadow Ops. REX et RAY restent disponibles.

- Metal Gear D : quinze pièces visibles et cinq points d’articulation, mouvement des jambes, pieds maintenus au sol pendant l’effondrement, puis séquence d’évacuation existante.
- TX-55 : seize pièces visibles et un ancrage, machine immobile, caméra à trois yeux, double lanceur nucléaire et disparition à la fin de la destruction existante. Le protocole de sabotage de cette adaptation et les alertes laser occupent la colonne gauche pour dégager la machine.
- Hangar de REX : quatre plans natifs, parallaxe suivant la caméra, animation légère des lumières et respect du réglage de mouvement réduit. Les fichiers sont chargés avant le combat concerné.

Les atlas PNG générés restent intacts. Découpes, superposition et articulations sont appliquées au rendu ; les maîtres, références, variantes rejetées et résultats de vérification sont conservés dans les archives de ce dossier. Les références documentent les incarnations d’origine ; une identité absolue pixel par pixel n’est pas certifiée.

La vérification couvre les contrats du rendu et du chargement, les régressions de Shadow Ops, ainsi que des actions réelles sur ordinateur et dans le module mobile. Les contrôles de victoire et de progression sont liés au SHA précis indiqué dans chaque rapport ; les essais refusés restent conservés. Les états de simulation du TX-55 sont stables en pause ; une variation de peinture Canvas observée est documentée séparément.

Les volumes `lossless/pass14-phase*-lossless-*.zip` sont limités à 8 Mio chacun. Les index permettent de reconstruire les sources à partir des objets uniques, y compris les objets déjà conservés dans les archives du lot précédent. Aucune version historique n’est supprimée.
