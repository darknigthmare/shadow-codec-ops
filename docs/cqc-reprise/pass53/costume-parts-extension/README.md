# « Quart de pluie » — gant proche

Une pièce supplémentaire du costume original CQC, dessinée à partir de la référence [Quart de pluie](../costume-parts/reference/dd-scout-quart-de-pluie-right.png) : le gant de cuir sombre du côté proche, en pose détendue.

- [PNG individuel transparent](quart-de-pluie-near-glove.png)
- [Prompt complet et référence](generation-prompts.json)
- [Provenance, empreinte et contrôles](manifest.json)

Le PNG brut est conservé sans retouche, recadrage, recoloration ou miroir. Un seul gant figure dans l’image. La pièce complète les trois accessoires précédents — casque, façade du gilet et genouillère — sans se substituer à leurs sources.

**Statut : source de revue.** Ce costume est une création originale CQC, pas un costume officiel. Le gant est un redessin isolé ; il n’est pas une extraction pixel pour pixel. Ses attaches, occlusions et placements par pose ne sont pas encore calibrés. Il ne remplace aucun sprite de combat.
