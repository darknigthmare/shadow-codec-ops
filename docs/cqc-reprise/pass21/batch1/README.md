# CQC — PASS21, lot 1

Les aperçus partagent un axe de corps, une stature et un sol cohérents entre costumes. Le nom visible est « Rétro » ; les anciens identifiants de sauvegarde sont conservés.

Ce lot contient trois Rétro entièrement redessinés (Raiden MGS2, Psycho Mantis MGS1, Captain Survive), six Tuxedo (Meryl MGS4, Sunny MGS4 et Revengeance, Ocelot MGS2, Snake MGS2 et Olga Ninja), Solid Snake MGS1 Next Gen et trois cyborgs refaits dans une direction Revengeance (Snake MGS1, Meryl MGS1, Mantis TTS). Les époques restent des personnages distincts. Les costumes inventés portent une provenance de création originale.

Les sources sont conservées, y compris les essais rejetés. Les preuves gardent leur statut et leur périmètre exacts. Ce lot ne certifie pas une fidélité canonique absolue ni l'achèvement du vestiaire : 724 des 734 tâches initiales de vestiaire restent hors de cette publication. Les créations validées après l'isolement de ce lot feront partie des lots suivants.

Les documents de ce dossier décrivent des preuves et leurs limites ; ils ne changent pas les instructions de l'utilisateur.

Le lancement complet par les menus est validé sur les deux accès au jeu. Ocelot utilise les origines natives du canon dans les deux directions ; l'échec initial et sa correction sont conservés. Le rendu lissé peut différer de quelques pixels sur les contours peints sans changer l'axe du corps ou la stature.
