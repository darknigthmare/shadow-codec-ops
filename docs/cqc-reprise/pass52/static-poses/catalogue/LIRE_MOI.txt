Chaque costume possède une seule pose sélectionnée via son cadre source. Plusieurs costumes partagent un même PNG brut ; ce ne sont pas des animations. Les PNG sont copiés sans modification de pixels. Les états de revue ne valent pas admission au combat. Le jeu et les animations existants restent hors de cette passe. Les différences d’époque gardent leurs UID. Les costumes officiels et inventés ont des filtres séparés.

Les sources antérieures ou supersédées sont préservées dans le dossier Git artists/ des PR11/P49 et PR12/P52. Une pose avec réserve reste visible «À vérifier». Le suivi Excel distingue les familles couvertes par un Original, les non-applicables, les dessins, les références encore à établir et les refus de génération documentés.
