Validation reproductible

Les tests Node vérifient la progression, la navigation, les sauvegardes et les messages du moteur avec un DOM en mémoire. Les rendus natifs utilisent le moteur de dessin réel. Ces vérifications ne sont pas des captures de navigateur ni des parties humaines ; les contrôles historiques conservent leurs dates et leur périmètre.

Le rapport est disponible dans tests/package-results-v056.json. Depuis un fichier local, certains navigateurs peuvent limiter sa lecture automatique.
