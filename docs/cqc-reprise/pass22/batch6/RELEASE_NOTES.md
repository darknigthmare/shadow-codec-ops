# Costumes natifs — Meryl MGS1 et Gala

Le costume Cyborg de Meryl MGS1 reçoit un dessin mécanique inspiré de Metal Gear Rising. Raikov MGS3, Teliko et Paz dans MGSV reçoivent leurs costumes Gala dessinés avec des orientations indépendantes. Ces adaptations conservent les identités propres à chaque période et les règles de combat existantes.

Les poses d'émission d'une seule frame restent visibles au premier dessin après leur activation, même lorsque la boucle avance plusieurs ticks entre deux affichages. La validation du lot porte sur les parcours et les ressources décrits dans les preuves jointes. Les sources remplacées ou rejetées sont conservées ; leurs statuts ne sont pas reclassés. Les limites de fidélité et de validation restent détaillées dans les reçus.
