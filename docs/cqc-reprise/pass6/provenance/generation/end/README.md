# The End — sprites natifs PASS6

Livraison du personnage `core__end`, incarnation originale de **Metal Gear Solid 3: Snake Eater (2004), PlayStation 2**. Six PNG natifs indépendants : A/B/C vers la droite et vers la gauche, soit 72 poses. Les images sélectionnées et les quatre essais rejetés restent inchangés ; toutes les générations originales, tous les prompts, arguments, références et SHA sont conservés.

`FINAL_DELIVERY.json` décrit les groupes d’actions et leur correspondance avec les dix entrées de combat. `SOURCE_COMBAT_ORIGINS.json` mesure quatre bouches de canon : tir normal et tir puissant, pour les deux orientations, sur la première image active. Les deux utilisent le même Mosin-Nagant conventionnel à crosse en bois. Le producteur ne modifie aucun profil de combat, moteur, catalogue ni fichier de production.

Les sept références sélectionnées ont été examinées visuellement. Le modèle couleur officiel Konami et les captures natives du jeu PS2 précisent la silhouette âgée, le camouflage de feuilles, les mains nues, la tête chauve peinte, le casque audio, la barbe, le perroquet et le Mosin. Les anciens chemins Konami qui renvoient une page HTML sont conservés comme recherches infructueuses, jamais comme références visuelles.

Fidélité : `closest_supported`. L’objectif est la fidélité 1:1 au plus proche des sources accessibles. Les poses sont des adaptations au mode Versus, sans certification absolue des pixels, du squelette ou des faces cachées. Les 72 poses ont été vues ; la validation indépendante des recadrages, pivots, phases, mobiles, départs des tirs et de l’intégration Shadow appartient à l’intégrateur.

Aucune retouche raster, symétrie, recoloration, modification d’alpha ou mise à l’échelle des PNG n’a été réalisée hors génération d’image. Le code d’inspection ne calcule que des métadonnées de géométrie et copie les octets natifs. La hauteur d’une pose accroupie, assise ou au sol n’est jamais utilisée pour agrandir le corps à la hauteur debout.
