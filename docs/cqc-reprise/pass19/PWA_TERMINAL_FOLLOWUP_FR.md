# Notifications du terminal

La revue visuelle de la version PASS19 en ligne a relevé une notification « Offline service worker linked. ». Les notifications d’installation, de connexion, de mise à jour et les réglages associés parlent désormais du terminal, en français. Les détails techniques d’une erreur restent dans la console ; le message affiché indique comment réessayer.

La connexion, l’installation, le fonctionnement hors ligne et les actions de mise à jour gardent les mêmes conditions. Les réglages précisent que seules les données déjà téléchargées restent accessibles hors ligne. Aucun sprite, stage, fichier du jeu CQC ou sauvegarde n’est modifié.

La compilation TypeScript, la compilation Vite/PWA et le contrôle PWA passent. Les 705 tests et les matchs de PASS19 restent les preuves du gameplay inchangé ; la notification et les deux accès font l’objet d’un contrôle en ligne après ce complément.
