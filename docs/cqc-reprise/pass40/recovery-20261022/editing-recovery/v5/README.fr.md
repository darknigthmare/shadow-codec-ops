Cette archive additive conserve les six fichiers manuels Liquid Support : adaptateur CQC54814, autorité des six poses, trois modifications ciblées du HTML, revue Root historique, fixtures et leur résultat. Les exports précédents restent distincts. Aucun PNG, métadonnée de costume, grand index généré, profil Chrome ou capture de session n’est inclus.

Les textes UTF-8 utilisent quatre préfixes : `@PROJECT_ROOT@`, `@APP_ROOT@`, `@WORKSPACE_ROOT@`, `@SCRATCH_ROOT@`. Leur inverse restitue les octets d’origine. Tous les paramètres de mouvement, de taille et de source sont conservés. Les anciens documents Root décrivent les octets historiques et ne valent pas nouvelle autorisation après restauration.

Avec Python 3.9 ou supérieur :

```sh
python hydrate-editing-export.py . NOUVEAU_DOSSIER --manifest-sha256 a1651597fcec1928b61485b4e45b2944363771b0e8eaee41eab003adf551e533
```

Les options `--app-root`, `--workspace-root` et `--scratch-root` règlent les autres racines. L’hydrateur vérifie tous les SHA avant la première écriture et refuse une destination existante. Il n’exécute aucun adaptateur ni fixture. Une restauration fraîche et les contrôles syntaxiques des deux sources JavaScript ont été effectués.
